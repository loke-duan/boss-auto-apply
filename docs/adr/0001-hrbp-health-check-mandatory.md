# 强制 HRBP 简历体检环节

在「解析简历(F1)」和「简历画像分析(F1.5)」之间，新增**强制**的 F1.6「HRBP 简历体检」环节。禁忌词/空洞表述/数据风险**不写死全局词表**，而是由 HRBP agent 对每份 master.json 逐条诊断，输出「简历体检报告」经用户确认后才进入方向推荐。

## 背景

用户原诉求：「禁忌词不能一刀切，每份新简历都要 HRBP 深度挖掘」。但 PRD v1.1 把禁忌词表写死在 F4，与该诉求冲突。同时用户要求「用可量化数值打动 HR」，但简历中现有数值存在基数不明、体量过小、反向暴露等风险。

## 决策

1. **新增 F1.6 HRBP 简历体检**（位置：F1 之后、F1.5 之前）：扫描禁忌词、标记数据风险、评估面试可答性，输出体检报告供用户确认。
2. **禁忌词不写死全局**：由 HRBP agent 逐份诊断（不同行业/岗位禁忌词不同）。
3. **F4 简历定制必须基于 F1.6 通过的 master.json**，不得绕过体检直接定制。

## 后果

- master.json 构建后多一道人工确认关（用户原决策 C9 已要求方向推荐确认，现扩展到内容质检）
- 简历定制质量上限由体检深度决定，体检 prompt 是核心资产
